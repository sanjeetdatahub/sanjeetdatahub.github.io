## 🌟 Key Features

1. **Dual Theme Architecture**:
   - **Deep Cyber Dark Mode**: Cyberpunk-inspired dark slate palette (`#0A0F1D`, `#0F172A`) with electric cyan (`#00F0FF`) and purple accents.
   - **Vibrant Color / Light Mode**: Crisp white glassmorphic cards with royal oceanic blue and emerald gradients.
   - Smooth toggle with persistent `localStorage` memory.
2. **Integrated Flagship Projects**:
   - **Banking Credit Risk & Loan Portfolio Analytics**: Probability of Default (PD), Expected Loss, IFRS 9 Multi-Stage Impairment, 88.4% ROC-AUC.
   - **Adidas US Sales Performance & Margin Analytics**: $157.4M Gross Sales across 9,648 transactions, product mix margins (Apparel 42% vs Footwear 36%), and retail channel efficiency.
3. **Interactive Live Data Playground / Simulator**:
   - Recruiter can drag sliders to calculate **Borrower Default Risk & Credit Tier** in real-time.
   - Recruiter can explore **Adidas Product & Channel Margin Projections**.
4. **Interactive Case Study Modals**:
   - Deep-dive popups displaying methodology, technical steps, business ROI, and high-resolution chart embeds.
5. **Mobile-First & Ultra-Responsive**:
   - Glassmorphic navigation, animated number counters, and working contact form.

## 🚀 How to Host on GitHub Pages in 2 Minutes (Free)

1. Create a new repository on GitHub named:
   `sanjeetdatahub.github.io` (or `portfolio`).
2. Run these commands inside this folder:
   ```bash
   cd /Users/sanjeetkumar/Desktop/sanjeet-analytics-portfolio
   git init
   git add .
   git commit -m "feat: initial release of modern data analyst portfolio"
   git branch -M main
   git remote add origin https://github.com/sanjeetdatahub/<REPO_NAME>.git
   git push -u origin main
   ```
3. In GitHub repo settings -> **Pages** -> Select branch `main` and root `/` -> Click **Save**.
4. Your website is instantly live at:
   `https://sanjeetdatahub.github.io/`!
